# MicaFlyouts

MicaFlyouts is a proof-of-concept WinUI 3 port of [FluentFlyout v2.15.0](https://github.com/unchihugo/FluentFlyout/tree/v2.15.0). I put this port together for fun. If you enjoy it, please consider supporting the original author.

This project reworks the Settings window with WinUI's built-in Fluent Design controls while staying as close as possible to the original's visual design. It also explores what WinUI 3 can bring over WPF: lower memory and disk usage, faster startup, and a more native system dialog experience.
